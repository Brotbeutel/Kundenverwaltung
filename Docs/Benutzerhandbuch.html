Digitale Kundenverwaltung (Sportless GmbH)


Herzlich willkommen zu Ihrer neuen digitalen Kundenverwaltung! Ab sofort gehört der lästige Zettelkram der Vergangenheit an. Dieses Handbuch führt Sie Schritt für Schritt durch das System. Alles ist einfach aufgebaut und leicht zu bedienen.

1. Erste Schritte: Wie logge ich mich ein?

Um mit dem System zu arbeiten, müssen Sie sich zuerst an Ihrem Computer oder Tablet anmelden. Das schützt die sensiblen Daten unserer Kunden.

Schritt-für-Schritt-Anleitung:

  1. Öffnen Sie das Programm an Ihrem Arbeitsplatz.
  2. Es erscheint die Anmeldeseite mit dem Hinweis: "Bitte melden Sie sich an, um fortzufahren."
  3. Geben Sie Ihren persönlichen Benutzernamen und Ihr Passwort in die dafür vorgesehenen Felder ein.
  4. Klicken Sie auf den Button "Anmelden".
⚠️ Wichtiger Sicherheitshinweis:

Wenn Sie Ihren Arbeitsplatz verlassen, schließt sich Ihre Sitzung nach 30 Minuten Inaktivität automatisch ab. Sie müssen sich dann aus Sicherheitsgründen neu anmelden.

2. Kundenverwaltung

Hier erledigen Sie Ihre tägliche Arbeit. Sie können Kunden finden, neue Kontakte eintragen oder veraltete Daten korrigieren.

Einen neuen Kunden anlegen:

  1. Klicken Sie in der Menüleiste auf den Punkt "Neuen Kunden anlegen".
  2. Es öffnet sich ein digitales Formular. Tragen Sie dort die Daten ein:
    • Vorname und Nachname
    • Firma (falls vorhanden)
    • Anschrift (Straße, Hausnummer, PLZ, Ort)
    • E-Mail-Adresse
  3. Überprüfen Sie Ihre Eingaben und klicken Sie auf "Speichern". Der Kunde ist nun sofort im System hinterlegt.

Kunden suchen und Daten bearbeiten:

  1. Nutzen Sie das Suchfeld auf Ihrer Startseite, um nach dem Namen des Kunden oder der Firma zu suchen.
  2. Klicken Sie auf den Namen des Kunden, um seine digitale Kundenkarte anzuzeigen.
  3. Wenn sich eine Adresse oder eine Telefonnummer geändert hat, klicken Sie auf "Bearbeiten".
  4. Ändern Sie die gewünschten Daten ab und klicken Sie am Ende auf "Änderungen speichern".

3. Wichtiger Hinweis zum Löschen von Kunden (DSGVO)

Der Schutz von Kundendaten ist gesetzlich streng geregelt (Datenschutz-Grundverordnung, kurz: DSGVO). Daher ist das System so eingestellt, dass normale Mitarbeiter keine Kunden löschen können.

  • Wer darf löschen? Nur der Administrator besitzt die Rechte, Daten endgültig aus dem System zu entfernen.
  • Was müssen Sie tun? Wenn ein Kunde gelöscht werden möchte (z. B. weil er kein Interesse mehr an Angeboten hat), wenden Sie sich bitte direkt an die Geschäftsleitung oder Ihren IT-Administrator. Dieser wird die Löschung sicher und gesetzeskonform für Sie durchführen.

4. Automatisierter E-Mail-Versand

Das System kann automatisch E-Mails an Ihre Kunden senden (z. B. Bestätigungen oder wichtige Informationen). Sie müssen dafür kein separates E-Mail-Programm öffnen.

Wie funktioniert das?

  • Das System versendet die Nachrichten im Hintergrund im Namen der Adresse: kundenverwaltung@sportless-gmbh.de.
  • Sobald Sie im System eine Aktion auslösen, die eine E-Mail erfordert (z. B. nach dem Anlegen eines Termins oder dem Absenden eines Formulars), generiert die Software die Nachricht ganz von allein.
  • Ihr Vorteil: Sie müssen keine Adressen mehr abtippen oder Texte kopieren – das System erledigt das fehlerfrei für Sie.
